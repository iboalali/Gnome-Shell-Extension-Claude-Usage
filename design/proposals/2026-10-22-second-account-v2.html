A second Claude account, restyled with St CSS

The menu stops padding text in a monospace font. Each limit is now a row of real St widgets: a fixed-width label column, a bar whose fill width is set from code, a right-aligned percentage and a dim reset time. The columns line up in any font, and the bar color uses the server's severity (green, amber, red, the same meaning as 🟢 🟡 🔴).

The first and last cells are real renders from a headless GNOME Shell 50.1 in Ubuntu mode: today's menu, and an St prototype of option 4 built with exactly this CSS. The five option mocks use the same measurements. All numbers are real readings from 22 Oct 08:10.

Evidence, not an option

What every option shares

  • Rows are St widgets, not padded text, so kv(), LABEL_WIDTH, fmtBar() and the claude-usage-mono class go away. The bar fill is a child St.Widget whose width is set in code as a share of the 128px track.
  • Colors come only from the severity the server sends. A normal limit is green even at 90%, matching how 🟢 works today.
  • An ACCOUNTS constant lists ~/.claude and ~/.claude-private. Each account gets its own OAuth timer, backoff, 401 check and cache file, and its own ccusage run with CLAUDE_CONFIG_DIR set. Private's ccusage reads 24 MB, so it adds little CPU.
  • ⚠️ still means every data path of every account is dead.
