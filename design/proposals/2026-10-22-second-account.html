What every option shares

  • An ACCOUNTS constant: [{label: 'Work', configDir: '~/.claude'}, {label: 'Private', configDir: '~/.claude-private'}]. The token comes from <configDir>/.credentials.json. ccusage runs with CLAUDE_CONFIG_DIR=<configDir>, so each account counts only its own transcripts.
  • Each account gets its own OAuth timer, jitter, 429 backoff, 401 same-token check and warm-start cache file. Each account still makes one request every 5-9 minutes against its own quota, but this machine makes twice as many requests in total.
  • A ccusage run for Private reads 24 MB, not 3.7 GB, so the second account adds little CPU. The transcript-change check runs per account.
  • ⚠️ still means every path of every account is dead.
